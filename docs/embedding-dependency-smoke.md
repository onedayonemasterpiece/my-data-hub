The smoke Notebook is private, internet-disabled, disposable, and pinned to the reviewed immutable image with pinning type `original`. It receives no Kaggle or database credential.

The receipt is secret-free and mode 0600. The private per-worker status Dataset contains the receipt and its hash; generated execution pins deny work when it is absent or mismatched.

The coordinator persists intent before provider mutation, reuses deterministic task/effect identities, and replays exact claim-bound cleanup after restart. Control reconciliation orders this after the exact master asset claim and before embedding launcher assembly.
